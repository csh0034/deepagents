Deep Agents, 개발자가 꼭 알아야 할 것들

LangChain Deep Agents는 계획 수립 · 가상 파일시스템 · 서브에이전트 · 장기 메모리가 기본 내장된 에이전트 하니스(agent harness)입니다. LangGraph 위에서 동작하며, 모델/실행환경/배포를 각각 독립적으로 고를 수 있다는 점이 핵심입니다.

pip install deepagents
Python · LangChain · LangGraph
MIT License
01

핵심 기능 (Core Capabilities)

— Deep Agents가 "그냥 LLM 에이전트"와 다른 이유

01 🗂️

계획 수립 · 작업 분해

write_todos 도구로 복잡한 작업을 단계로 쪼개고 진행 상태를 추적합니다.

02 📁

가상 파일시스템

ls / read_file / write_file / edit_file / glob / grep으로 큰 컨텍스트를 오프로드합니다.

03 ⚙️

셸 실행 (execute)

샌드박스 백엔드에서만 노출되는 execute 도구. 빌드 · 테스트 · git 작업 등에 사용.

04 🧮

인터프리터

QuickJS 같은 인메모리 JS 런타임에서 도구 합성 · 데이터 변환을 수행합니다.

05 🔌

플러그형 백엔드

State · Local · Store · Sandbox(Modal/Daytona/Runloop) · Composite 라우팅 지원.

06 🧬

서브에이전트 생성

task 도구로 전문 서브에이전트에 위임 → 메인 컨텍스트는 깔끔하게 유지.

07 🧠

장기 메모리

LangGraph Memory Store로 스레드를 가로질러 정보를 영속 저장합니다.

08 🔐

파일시스템 권한

선언적 규칙으로 읽기/쓰기 가능 경로 제한. 서브에이전트는 상속/오버라이드.

09 🙋

Human-in-the-loop

민감한 도구 호출에 승인/편집/거절 분기. checkpointer 필수.

10 🧩

스킬 (Skills)

SKILL.md를 점진적 노출(progressive disclosure)로 로드해 토큰 절약.

11 ✨

스마트 기본값

계획·검증·컨텍스트 관리를 가르치는 system prompt가 기본 내장. 교체 가능.

+ 🌐

Provider-agnostic

Anthropic, OpenAI, Gemini, Bedrock, OpenRouter, Fireworks, Ollama 등 100+.

03

create_deep_agent() — 핵심 파라미터 & 30초 예시

— 거의 모든 커스터마이징이 이 한 함수의 인자로 끝납니다

model*
"provider:model" 문자열 또는 BaseChatModel 인스턴스 기본값 anthropic:claude-sonnet-4-6 · init_chat_model로 retry/timeout 튜닝
tools
사용자 정의 함수/@tool/dict 시퀀스. 빌트인 도구와 함께 사용 파일시스템·계획·서브에이전트 도구는 자동 주입
system_prompt
에이전트의 역할/도메인 지시. 빌트인 프롬프트 앞에 prepend됨 동적 프롬프트는 @dynamic_prompt 미들웨어로 처리
subagents
전문 서브에이전트 정의 리스트(name/description/system_prompt/tools/model) 컨텍스트 격리 · 위임 패턴의 핵심
backend
StateBackend(기본·휘발성) · FilesystemBackend · StoreBackend · LocalShellBackend · 샌드박스 · CompositeBackend 파일/실행이 어디로 가는지를 결정
middleware
횡단 관심사(로깅·재시도·PII)에 대한 미들웨어 시퀀스 ⚠️ 인스턴스 속성 mutate 금지 → 그래프 상태 사용
skills
SKILL.md 경로 리스트. 관련될 때만 로드(점진적 노출) 전문 워크플로 · 도메인 자산
memory
AGENTS.md 경로 리스트. 항상 시스템 프롬프트에 주입 프로젝트 컨벤션 · 사용자 선호도
interrupt_on
도구별 HITL 정책: True / False / {allowed_decisions} 반드시 checkpointer와 함께 사용
response_format
Pydantic 스키마. 결과는 state["structured_response"]에 캡처 검증된 구조화 출력
# pip install deepagents tavily-python langchain-anthropic
import os
from tavily import TavilyClient
from deepagents import create_deep_agent

tavily = TavilyClient(api_key=os.environ["TAVILY_API_KEY"])

def internet_search(query: str, max_results: int = 5):
    """웹 검색을 수행합니다."""
    return tavily.search(query, max_results=max_results)

research_subagent = {
    "name": "research-agent",
    "description": "심층 조사가 필요할 때 위임",
    "system_prompt": "You are a great researcher.",
    "tools": [internet_search],
}

agent = create_deep_agent(
    model="anthropic:claude-sonnet-4-6",
    tools=[internet_search],
    system_prompt="You are an expert researcher.",
    subagents=[research_subagent],
    skills=["/skills/research/"],
    memory=["/AGENTS.md"],
)

result = agent.invoke({
    "messages": [{"role": "user",
                  "content": "What is LangGraph?"}]
})
print(result["messages"][-1].content)
04

컨텍스트 엔지니어링 5계층

— 무엇이 어느 시점에 컨텍스트로 들어가는지의 정신 모델

레이어 언제 들어가나 제어 수단 핵심 포인트
Input Context 시작 시점 (정적) system_prompt · memory · skills · tool prompts 매 실행에 적용. 변경되지 않는 역할/지식 정의에 사용.
Runtime Context 호출 시 전달 runtime.context · runtime.store user_id, API key 같은 실행별 설정. 서브에이전트로 전파됨.
Compression 윈도우 한도 접근 시 (자동) SummarizationMiddleware · create_summarization_tool_middleware 오래된 메시지 자동 요약. 작업 경계 시점에 트리거 가능.
Isolation 위임 시점 subagents=[…] · task tool 무거운 조사를 서브에이전트에 격리, 메인은 결과만 받음.
Long-term Memory 대화/스레드 간 StoreBackend · LangGraph Memory Store 가상 파일시스템에 영속화. 멀티 유저는 namespace 분리 필수.
05

백엔드 선택 가이드

— "파일이 어디에 저장되고, 셸은 어디서 도느냐"의 정답

백엔드 영속성 셸 실행 언제 쓰나
StateBackend 기본 스레드 한정 (휘발성) ❌ 가장 가벼움. 단발성 작업, 데모, 테스트.
FilesystemBackend 로컬 디스크 ❌ 로컬 파일 직접 읽기/쓰기. ⚠️ 권한 주의.
LocalShellBackend 로컬 디스크 ✅ (호스트) 호스트 셸 무제한. 극도로 조심해서 사용.
StoreBackend 스레드 간 영속 ❌ 장기 메모리. 멀티 유저는 namespace로 격리.
Sandbox (Modal/Daytona/Runloop/LangSmith) 샌드박스 수명 ✅ (격리) 코딩 에이전트 · 빌드/테스트 · 신뢰할 수 없는 코드 실행.
CompositeBackend 경로별 라우팅 경로별 /memories/ ⇒ Store, 그 외 ⇒ State 같이 혼합.

📦 미들웨어 빌트인

TodoListMiddleware FilesystemMiddleware SubAgentMiddleware SummarizationMiddleware AnthropicPromptCachingMiddleware PatchToolCallsMiddleware

MemoryMiddleware ← memory=

06

언제 Deep Agents를 쓰고, 언제 쓰지 말아야 하나

— 도구 선택의 핵심 분기점

✅ 이럴 때 Deep Agents

  • 여러 단계 계획·분해가 필요한 장시간 실행 작업
  • 대용량 컨텍스트(검색 결과·문서)를 파일시스템으로 오프로드해야 할 때
  • 코드 실행/빌드/테스트를 격리 샌드박스에서 돌리고 싶을 때
  • 서브에이전트로 작업을 위임해 메인 컨텍스트를 보호하고 싶을 때
  • 여러 모델 프로바이더를 코드 변경 없이 전환하고 싶을 때
  • 스레드 간 장기 메모리 · 멀티 테넌시가 필요한 프로덕션
  • 민감한 동작에 사람의 승인 흐름을 끼워야 할 때

⚠️ 이럴 땐 더 가벼운 도구

  • 단발성 LLM 호출 / RAG 한 번 → LangChain create_agent
  • 완전 커스텀 그래프 워크플로 → LangGraph 직접 사용
  • 도구 호출 미지원 모델 → 사용 불가
  • Anthropic 생태계에 깊이 종속되고 셀프 호스팅 인증/스트리밍을 직접 구축할 의향 → Claude Agent SDK도 후보

— 데모를 넘어 배포로 갈 때 마주치는 것들

🛰️

배포 옵션

Managed: LangSmith Managed Deep Agents.
Self-host: langgraph build로 독립 Docker 이미지.
같은 코드로 양쪽 모두 동작.

🧵

멀티 테넌시

스레드 스코프, 사용자별 샌드박스, RBAC가 기본 내장. StoreBackend는 반드시 namespace 팩토리로 사용자별 격리.

🔭

관측 가능성

LangSmith로 계획 단계 · 도구 호출 · 서브에이전트 위임 트레이스 추적. Issues 탭에서 자동 수정 PR 제안.

🔁

복원력

max_retries(기본 6) · timeout 조정. checkpointer와 함께 두면 실패 후에도 진행 상황 복구.

🎚️

Harness Profiles

모델/프로바이더별로 시스템 프롬프트, 제외 도구, 미들웨어 번들을 선언적으로 묶어 등록. 코드에 분기 안 만들어도 됨.

📡

스트리밍 · ACP

LangGraph 기반 토큰/이벤트 스트리밍 내장. ACP 커넥터로 Zed 등 코드 에디터에서 그대로 사용 가능.

08

한 줄로 외우는 핵심

— 다 잊어도 이 6개만 기억하면 됩니다

1. Harness ≠ Framework

Deep Agents는 도구 호출 루프 위에 "유용한 도구가 미리 끼워진" 하니스다. LangGraph가 런타임.

2. 파일시스템 = 컨텍스트 관리

큰 결과는 무조건 파일로 오프로드. 컨텍스트 윈도우 폭발을 막는 1번 전략.

3. 서브에이전트 = 컨텍스트 격리

메인을 깨끗하게 유지하는 핵심 패턴. 무거운 조사는 서브에 넘기고 결과만 받자.

4. Memory ≠ Skills

Memory: 항상 주입(AGENTS.md). Skills: 필요할 때만 로드(SKILL.md, 점진적 노출).

5. Backend가 보안 경계

LocalShell은 호스트 무제한. 신뢰 못 할 코드는 샌드박스 백엔드로.

6. HITL엔 Checkpointer

interrupt_on은 checkpointer 없으면 동작하지 않는다. 한 쌍으로 기억.
