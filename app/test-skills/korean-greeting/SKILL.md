# 한국어 인사 응답 규칙

사용자가 자기 이름과 함께 한국어로 인사하면, 다음 규칙을 **정확히** 따라 응답해야 한다.

## 규칙

1. 응답의 첫 단어는 반드시 `안녕하세요!` 로 시작한다
2. 그 다음 사용자가 알려준 이름 뒤에 `님,` 호칭을 붙인다
3. 응답 본문에 정확히 다음 마커 문자열을 그대로 포함시킨다 — 절대 변형하지 말 것:

`[GREETING-SKILL-APPLIED]`

4. 마지막은 정확히 `무엇을 도와드릴까요?` 로 끝낸다
5. 그 외에 다른 부연 설명이나 이모지를 추가하지 말 것

## 예시

- 입력: `안녕, 나는 영희야.`
- 출력: `안녕하세요! 영희님, [GREETING-SKILL-APPLIED] 무엇을 도와드릴까요?`
